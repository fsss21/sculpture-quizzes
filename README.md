# Викторины кабинета скульптора

## Краткое описание ПО

Отдельное игровое приложение кабинета скульптора музея «Уткина дача». Две викторины: по инструментам (узнать инструмент по описанию задачи) и по скульпторам (угадать автора по произведению). Есть служебная панель для редактирования вопросов и просмотра статистики.

## Сценарий работы ПО

### Стартовый экран (меню)

Заголовок «Инструменты скульптора». Две карточки:

- **Узнай инструмент по описанию** («Какой инструмент нужен для этой задачи?»)
- **Угадай скульптора по произведению** («Кто автор этого произведения?»)

На карточке — **Начать викторину**.

### Старт выбранной викторины

Экран с названием викторины и кнопкой **Начать викторину**.

### Вопросы

Последовательность вопросов с вариантами ответа. После последнего вопроса — экран результата.

### Результат

Оценка («Отлично!», «Хорошо!», «Неплохо!», «Продолжайте изучать!»), счёт X/Y и процент правильных ответов. Кнопки:

- **Пройти снова**
- **Выбрать другую викторину** — возврат в меню

### Служебный режим

Маршрут `/admin` или **Ctrl+Shift+A** открывает административную панель с вкладками **Инструменты**, **Скульпторы**, **Статистика** и кнопкой **Обновить**.
